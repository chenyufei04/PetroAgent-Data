# 算法模块预留说明

该目录用于后续接入石油工程数据清洗、质量检测和模型推理算法。当前仅建立目录边界，不包含未经真实数据验证的算法实现。

## 目录职责

- `preprocessing/`：字段标准化、类型转换、单位换算、重复数据处理。
- `imputation/`：缺失值识别、插值、统计填补和模型填补。
- `anomaly_detection/`：失真、离群点、突变、漂移和跨字段异常检测。
- `staleness/`：陈旧数据、过期标准、长期未更新记录和数据新鲜度评分。
- `models/`：模型封装、加载、版本信息和统一推理接口。
- `pipelines/`：解析、清洗、检测、复核和报告生成的编排流程。
- `evaluation/`：准确率、召回率、误报率、稳定性和回归评估。

正式实现前，应先取得脱敏真实样本，确认字段、单位、时间粒度、工况、缺失方式以及可用标签。

所有算法应保留原始值、建议值、置信度、模型或规则版本，不得静默覆盖原始工程数据。
